# Security

Found a vulnerability in the Dread List (dreadlist.co.uk or this code)? Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/CyberSecDigestDaily/dread/security/advisories/new)
rather than a public issue. It's a personal project, so there's no bounty, but reports are read and fixed quickly.

In scope: the site, its API (`/api/*`), sign-in (passkeys, recovery and device codes), sessions, shared lists and
public profiles. Out of scope: denial of service by volume, findings that need a compromised device or browser, and
reports from automated scanners without a working proof of concept.

How it's built and protected is described in the README under "Privacy and security".
