    Probably skip these

    • Bone Tomahawk (2015). Mostly a slow-burn western, then one infamously brutal scene that’s pure Hostel territory.
    • Terrifier 1–3. Gore showcases first, films second.
    • The Sadness (2021). An outbreak film built around sadistic violence.
    • When Evil Lurks (2023). Superb, but relentlessly cruel, including to kids and animals.
    • Bring Her Back (2025). Brilliant and genuinely nasty. The most uncomfortable horror of last year.
    • Infested (2023). Great reviews, but it’s wall-to-wall spiders.

    Sync across devices

    Your ticks and scores are saved to a file in a private GitHub repository, so they follow you between your phone, laptop and PC. Paste a fine-grained token that has Contents: read and write on that repository. The token stays in this browser and is only ever sent to api.github.com.

    Firefox set to clear site data on close will forget the token. Add an exception for this site under Settings, Privacy & Security, Cookies and Site Data, Manage Exceptions.
